# Manual publication

Create a separate empty GitHub repository named DataEater-builder (or a name you choose).
Publish this project's tracked files only, retaining LICENSE, NOTICE and THIRD_PARTY_NOTICES.md.
Do not publish local Python environments, review exports, original manuals, generated databases,
creator keys, secret files or the Android project's private history. Resolve applicable PyMuPDF
AGPL/commercial terms before distributing a packaged PDF-enabled executable.

The owner uploads manually. No remote address is assumed. The independent initial history does
not include earlier Android commits. Compatibility is through the existing `.dataeater` format.
